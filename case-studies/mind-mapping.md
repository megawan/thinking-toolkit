# Case study: Planning a community finance workshop

> Illustrative scenario. It is a composite written to show the method in use, not a report about a real organisation.

Method: [Mind Mapping](../methods/ideation/mind-mapping.md)

## Context

A volunteer group wanted to run a one-day personal finance workshop for young adults, but ideas came in a jumble: topics, venues, speakers and worries mixed together.

## What was done

- The organiser put the workshop in the centre and drew seven main branches: audience, content, format, logistics, promotion, budget and risks
- The group added keywords under each branch for fifteen minutes
- They drew links, for example between sponsorship (budget) and speakers (content)
- Budget and risks were visibly thin

## Outcome

The group added sponsorship options and a backup speaker, then turned each branch into a checklist with an owner.

## Lessons

- The map showed gaps that a list had hidden
- Cross-links revealed dependencies
- A checklist per branch turned the map into a plan
