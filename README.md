# thinking-toolkit

A collection of practical thinking methods for solving problems, generating ideas, and making decisions.

Each method is a short, self-contained guide: what it is, when to use it, how to apply it, a worked example, and common pitfalls.

## Methods

<!-- methods:start -->
| Method | Category | In short |
| --- | --- | --- |
| [SWOT Analysis](methods/swot.md) | Analysis and strategy | Map what you do well, where you are weak, what the outside offers, and what threatens you, then turn that map into choices. |
| [Six Thinking Hats](methods/six-thinking-hats.md) | Group thinking and decision making | Look at a problem from six separate angles, one at a time, so a group stops arguing across each other. |
| [Lateral Thinking](methods/lateral-thinking.md) | Idea generation | Step sideways instead of pushing harder down the same road, to find solutions logic alone would not reach. |
| [Eisenhower Matrix](methods/eisenhower-matrix.md) | Prioritisation and decision making | Sort tasks by urgency and importance so you spend your time on what matters, not only on what shouts loudest. |
| [First Principles](methods/first-principles.md) | Problem solving | Break a problem down to what is certainly true, then build the solution up from there instead of copying what already exists. |
| [Five Whys](methods/five-whys.md) | Root cause analysis | Ask "why?" again and again until you reach a cause you can fix, not just a symptom you can patch. |
<!-- methods:end -->

More methods will be added over time. The table above is generated; see [CONTRIBUTING.md](CONTRIBUTING.md).
