# Eisenhower Matrix

> Sort tasks by urgency and importance so you spend your time on what matters, not only on what shouts loudest.

| | |
| --- | --- |
| **Category** | Prioritisation |
| **Time needed** | 10-20 minutes, then a few minutes daily or weekly |
| **Best for** | Overloaded to-do lists, competing demands, and planning your week |

## What it is

The Eisenhower Matrix is a simple prioritisation tool built on one distinction: **urgent** tasks demand immediate attention, while **important** tasks contribute to your long-term goals and values. The two are not the same. It is named after US President Dwight D. Eisenhower, who is said to have organised his work this way, and was popularised by Stephen Covey as the "time management matrix".

## The four quadrants

| | Urgent | Not urgent |
| --- | --- | --- |
| **Important** | **1. Do first.** Crises, deadlines, urgent problems | **2. Schedule.** Planning, learning, health, relationships, prevention |
| **Not important** | **3. Delegate.** Interruptions, some calls and emails, others' requests | **4. Eliminate.** Time-wasters, busywork, mindless scrolling |

## Why it works

Without a filter, urgent items crowd out important ones. People spend their days reacting (quadrants 1 and 3) and rarely get to the work that changes things (quadrant 2). The matrix makes the trade-off visible and turns "I am too busy" into a concrete choice about what to do, delay, hand off, or drop.

## When to use

- Your to-do list is long and everything feels pressing
- You are always reacting and rarely planning
- A team needs to agree on priorities
- You are starting a week or a project

## When not to use

- You have two or three tasks; just do them
- You need to rank items against each other in fine detail; use a scored method
- The list is unclear; clarify the tasks first

## How to apply

1. **Brain-dump all tasks.** Write everything you need or want to do.
2. **Define the goal.** Importance is relative to something: your goals, role, or project.
3. **Rate urgency.** Does it have a near deadline or a consequence if delayed?
4. **Rate importance.** Does it move you toward a key goal? What happens if it never gets done?
5. **Place each task** in a quadrant.
6. **Act by quadrant:**
   - **Quadrant 1:** Do now, in order of deadline.
   - **Quadrant 2:** Put in the calendar with a specific time. Protect it.
   - **Quadrant 3:** Delegate, automate, or give a short, standard reply.
   - **Quadrant 4:** Drop, or do only as a deliberate break.
7. **Review regularly.** Quadrant 2 items become quadrant 1 if left too long.

## Test questions

| Question | If yes |
| --- | --- |
| Does it have a deadline in the next day or two with a real consequence? | Urgent |
| Does it serve a goal I would name if asked? | Important |
| Could someone else do this just as well? | Delegate |
| Would anything bad happen if I never did it? | If no, eliminate |
| Is this urgent only because someone else is pushing? | Probably quadrant 3 |

## Example

A project manager's Monday:

| Task | Urgent | Important | Quadrant | Action |
| --- | --- | --- | --- | --- |
| Fix the broken payment page | Yes | Yes | 1 | Do now |
| Client proposal due Wednesday | Yes | Yes | 1 | Do today |
| Write the quarterly roadmap | No | Yes | 2 | Block Thursday 09:00-11:00 |
| Learn the new reporting tool | No | Yes | 2 | Schedule 30 min on Friday |
| Reply to a vendor about an invoice query | Yes | No | 3 | Ask finance to handle it |
| Attend an optional status call | Yes | No | 3 | Decline, read the notes |
| Reorganise old shared folders | No | No | 4 | Drop |
| Check social media | No | No | 4 | Limit to lunch break |

## Tips

- Aim to move more time into quadrant 2. That is where prevention and growth happen, and it reduces future quadrant 1 crises.
- Limit quadrant 1 per day to what you can finish; a long list means you need to plan earlier.
- Do not use "urgent" for things that only feel pressing; check the real consequence.
- With a team, agree on what "important" means before sorting.
- Pair with a calendar: tasks with no time slot are only wishes.

## Pitfalls

- **Everything is "important".** Tie importance to a stated goal.
- **Living in quadrant 1.** A constant stream of crises signals a planning problem.
- **Ignoring quadrant 2.** It never feels urgent, so it needs deliberate scheduling.
- **Delegating without context.** Quadrant 3 hand-offs need clear instructions.
- **Sorting but not acting.** The matrix only helps if the plan reaches your calendar.
- **Doing it once.** Priorities change; review weekly.

## Quick checklist

- [ ] All tasks listed
- [ ] Goals for "important" are clear
- [ ] Each task placed in a quadrant
- [ ] Quadrant 2 items have calendar slots
- [ ] Delegations assigned
- [ ] Quadrant 4 items dropped
- [ ] Review time set
