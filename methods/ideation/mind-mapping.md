# Mind Mapping

> Put the central topic in the middle and branch outward, so you can see ideas and how they connect on one page.

| | |
| --- | --- |
| **Category** | Idea generation |
| **Time needed** | 15-45 minutes, solo or in a group |
| **Best for** | Exploring a topic, collecting ideas, and organising thoughts before writing or planning |

## What it is

A mind map is a diagram that starts from one central topic and grows outward in branches. Main branches hold the major themes, and smaller branches hold details and related ideas. The format was popularised by Tony Buzan in the 1970s, though radial note-taking is much older.

The structure mirrors how ideas link to one another, instead of forcing them into a straight list. Each new idea attaches to an earlier one, which prompts further ideas nearby.

## Why it works

Lists force a sequence on ideas that are not sequential. A map lets you add a thought wherever it belongs, see gaps where a branch is thin, and notice links between branches. Using single keywords instead of sentences keeps the pace high and the map readable.

## When to use

- You need to explore a topic before deciding what to do
- A brainstorm produced many ideas that need structure
- You are planning a talk, a document, or a project
- You want to take notes that show relationships
- A group needs a shared picture of what is known

## When not to use

- The task is a strict sequence of steps; a numbered list is clearer
- You need numbers or precise comparisons; use a table or [Decision Matrix](../decision-making/decision-matrix.md)
- The topic is already well understood and only needs writing up

## How to apply

1. **Write the central topic** in the middle of a blank page, as a short phrase or image.
2. **Draw main branches** from the centre, one for each major theme. Label each with one word or a short phrase.
3. **Add sub-branches** off each main branch for details, examples, and questions. Use keywords, not sentences.
4. **Keep going outward.** Let one idea trigger the next. Do not stop to judge.
5. **Link across branches** with lines or arrows where ideas connect.
6. **Use colour, icons or shapes** to group themes and mark priorities.
7. **Review the map.** Look for thin branches that need more thought, and for clusters that suggest a plan.
8. **Turn it into action.** Pick the branches that matter and write next steps.

## Tips

- Use landscape orientation and plenty of space
- One keyword per branch; short is faster and clearer
- If a branch gets crowded, give it its own map
- Start with themes you can already name (who, what, why, how, when, where) if you are stuck
- In a group, draw on a whiteboard so everyone can add branches

## Example: planning a community workshop

**Topic:** Run a one-day workshop on personal finance for young adults.

| Main branch | Sub-branches |
| --- | --- |
| Audience | Age 18-25; first job; students; what they already know |
| Content | Budgeting; saving; debt; taxes; investing basics |
| Format | Talks; group exercises; case examples; take-home worksheet |
| Logistics | Venue; date; equipment; catering; registration |
| Promotion | Campus groups; social media; local employers |
| Budget | Speakers; venue cost; materials; sponsorship |
| Risks | Low turnout; speaker cancels; venue double-booked |

**Reading the map:** The Budget and Risks branches are thin. The organiser adds sponsorship options and a backup speaker, then turns each branch into a checklist.

## Pitfalls

- **Writing sentences.** Long phrases slow the map and clutter it.
- **Over-organising too early.** Collect first, restructure afterwards.
- **A map that is only a list.** Add cross-links to show relationships.
- **No outcome.** A map is a thinking aid; finish by choosing actions.
- **Too many main branches.** Around five to nine is easy to take in.
- **Never revisiting.** Update the map as you learn more.

## Quick checklist

- [ ] Central topic is a short phrase or image
- [ ] Main branches are distinct themes
- [ ] Keywords, not sentences
- [ ] Cross-links drawn
- [ ] Thin or missing branches noticed
- [ ] Next steps chosen from the map
