# Choose a method

Find your situation, then open the method that fits. If several are listed, the first is the usual starting point. For multi-step sequences, see [Workflows](workflows.md).

## I am stuck

| Situation | Try |
| --- | --- |
| Every option looks the same | [Lateral Thinking](../methods/ideation/lateral-thinking.md) |
| I have something that works but want it better | [SCAMPER](../methods/ideation/scamper.md) |
| People say "that is just how it works" | [First Principles](../methods/mental-models/first-principles.md) |
| My plan feels vague | [Inversion](../methods/mental-models/inversion.md) |
| I need a quick set of different designs | [Crazy 8s](../methods/ideation/crazy-8s.md) |
| Loud voices dominate our brainstorms | [Brainwriting 6-3-5](../methods/ideation/brainwriting-635.md) |
| I have a problem from my field that others may have solved | [Analogical Thinking](../methods/ideation/analogical-thinking.md) |
| The solution has several separate design choices | [Morphological Analysis](../methods/ideation/morphological-analysis.md) |
| I have a pile of thoughts and need a picture | [Mind Mapping](../methods/ideation/mind-mapping.md) |
| The problem is stated as a complaint | [How Might We](../methods/ideation/how-might-we.md) |

## Something went wrong

| Situation | Try |
| --- | --- |
| The same problem keeps coming back | [Five Whys](../methods/root-cause/five-whys.md) |
| There are many possible causes | [Fishbone Diagram](../methods/root-cause/fishbone.md) |
| I have lots of problems and need to know which matter most | [Pareto Analysis](../methods/prioritisation/pareto-analysis.md) |

## I need to decide

| Situation | Try |
| --- | --- |
| Several options and several criteria | [Decision Matrix](../methods/decision-making/decision-matrix.md) |
| The team argues past each other | [Six Thinking Hats](../methods/decision-making/six-thinking-hats.md) |
| I want to know how one option could go wrong | [Pre-mortem](../methods/strategy-and-risk/pre-mortem.md) |
| I want a broad view of an option or a business | [SWOT Analysis](../methods/strategy-and-risk/swot.md) |
| The choice is about money and I can estimate costs and benefits | [Cost-Benefit Analysis](../methods/decision-making/cost-benefit-analysis.md) |
| Outcomes are uncertain, or my time has other uses | [Expected Value and Opportunity Cost](../methods/decision-making/expected-value-and-opportunity-cost.md) |
| A big life or career choice that numbers do not settle | [Regret Minimization](../methods/decision-making/regret-minimization.md) |
| I am about to react in the heat of the moment | [10-10-10](../methods/decision-making/ten-ten-ten.md) |
| I do not know how much care this decision needs | [One-way and Two-way Doors](../methods/decision-making/one-way-and-two-way-doors.md) |
| The situation changes faster than we can plan | [OODA Loop](../methods/decision-making/ooda-loop.md) |

## I have too much to do

| Situation | Try |
| --- | --- |
| Everything feels urgent | [Eisenhower Matrix](../methods/prioritisation/eisenhower-matrix.md) |
| A long list of issues with data behind it | [Pareto Analysis](../methods/prioritisation/pareto-analysis.md) |
| A release must fit a fixed date and everyone says their item is essential | [MoSCoW](../methods/prioritisation/moscow.md) |
| A long backlog needs a ranking on evidence | [RICE and ICE Scoring](../methods/prioritisation/rice-and-ice-scoring.md) |
| I want a quick visual sort of ideas into quick wins and money pits | [Impact-Effort Matrix](../methods/prioritisation/impact-effort-matrix.md) |

## I need to plan or set goals

| Situation | Try |
| --- | --- |
| A vague wish needs to become a clear goal | [SMART Goals](../methods/planning/smart-goals.md) |
| The team needs focus and alignment this quarter | [OKR](../methods/planning/okr.md) |
| The goal is far away and the path is unclear | [Backcasting](../methods/planning/backcasting.md) |
| I want to test the plan before starting | [Pre-mortem](../methods/strategy-and-risk/pre-mortem.md) |

## I am starting something new

| Situation | Try |
| --- | --- |
| Check the idea from the ground up | [First Principles](../methods/mental-models/first-principles.md) |
| Find risks before the team commits | [Pre-mortem](../methods/strategy-and-risk/pre-mortem.md) |
| Understand where we stand | [SWOT Analysis](../methods/strategy-and-risk/swot.md) |
| Generate approaches | [Lateral Thinking](../methods/ideation/lateral-thinking.md) |
| Explore the topic first | [Mind Mapping](../methods/ideation/mind-mapping.md) |
| Frame the challenge | [How Might We](../methods/ideation/how-might-we.md) |

## The team is in a meeting

| Situation | Try |
| --- | --- |
| Discussion goes in circles | [Six Thinking Hats](../methods/decision-making/six-thinking-hats.md) |
| Nobody raises concerns | [Pre-mortem](../methods/strategy-and-risk/pre-mortem.md) |
| We cannot agree between options | [Decision Matrix](../methods/decision-making/decision-matrix.md) |
| The same blocker appears each sprint | [Five Whys](../methods/root-cause/five-whys.md) |

## I need to think more clearly

| Situation | Try |
| --- | --- |
| A change looks good at first glance but I worry about side effects | [Second-order Thinking](../methods/mental-models/second-order-thinking.md) |
| Several explanations fit the facts | [Occam's and Hanlon's Razor](../methods/mental-models/occams-and-hanlons-razor.md) |
| I need a number but have no data | [Fermi Estimation](../methods/mental-models/fermi-estimation.md) |
| New evidence has arrived and I need to update my view | [Bayesian Thinking](../methods/mental-models/bayesian-thinking.md) |
| The problem has loops and keeps coming back | [Systems Thinking](../methods/mental-models/systems-thinking.md) |

## I disagree with someone, or I want to test an idea

| Situation | Try |
| --- | --- |
| I want to understand the other side's best case | [Steel-manning](../methods/critical-thinking/steel-manning.md) |
| I want to examine a claim or help someone think it through | [Socratic Questioning](../methods/critical-thinking/socratic-questioning.md) |
| The plan needs to be attacked before reality does it | [Red Team and Devil's Advocate](../methods/critical-thinking/red-team-and-devils-advocate.md) |
| I suspect my judgment was affected by a bias | [Cognitive Biases](../methods/critical-thinking/cognitive-biases.md) |
| I am sure about someone's motives and want to check | [Ladder of Inference](../methods/critical-thinking/ladder-of-inference.md) |
| An argument sounds convincing but something feels off | [Logical Fallacies](../methods/critical-thinking/logical-fallacies.md) |
| I want to see what an argument rests on and where it is weak | [Argument Mapping and Toulmin Model](../methods/critical-thinking/argument-mapping-and-toulmin.md) |
| A claim comes with excuses and no test could ever disprove it | [Falsifiability](../methods/critical-thinking/falsifiability.md) |
| Someone says "prove me wrong" | [Burden of Proof](../methods/critical-thinking/burden-of-proof.md) |
| Two things moved together and I am asked to act on it | [Correlation vs Causation](../methods/critical-thinking/correlation-vs-causation.md) |
| A claim leans on statistics, probability or a rhetorical trick | [Statistical and Rhetorical Fallacies](../methods/critical-thinking/statistical-and-rhetorical-fallacies.md) |

## I am designing for people

| Situation | Try |
| --- | --- |
| I do not know why customers choose or leave | [Jobs To Be Done](../methods/design-and-product/jobs-to-be-done.md) |
| The problem is unclear and involves human behaviour | [Design Thinking](../methods/design-and-product/design-thinking.md) |
| The team jumps to solutions or never decides | [Double Diamond](../methods/design-and-product/double-diamond.md) |
| I have research notes and need a shared picture of the user | [Empathy Map](../methods/design-and-product/empathy-map.md) |
| The experience crosses many steps and teams | [User Journey Map](../methods/design-and-product/user-journey-map.md) |
| I want to check that my offer matches what the customer needs | [Value Proposition Canvas](../methods/design-and-product/value-proposition-canvas.md) |

## I am looking at a market or a business

| Situation | Try |
| --- | --- |
| Is this industry attractive, and where does the pressure come from? | [Porter's Five Forces](../methods/strategy-and-risk/porters-five-forces.md) |
| What outside trends and rules could affect us? | [PESTEL Analysis](../methods/strategy-and-risk/pestel-analysis.md) |
| I need the whole business on one page | [Business Model and Lean Canvas](../methods/strategy-and-risk/business-model-and-lean-canvas.md) |

## I want to learn from what happened

| Situation | Try |
| --- | --- |
| The team wants to improve how it works together | [Retrospective](../methods/reflection-and-learning/retrospective.md) |
| An event has just finished and I want to capture the lessons | [After Action Review](../methods/reflection-and-learning/after-action-review.md) |
| I want to be sure I really understand something | [Feynman Technique](../methods/reflection-and-learning/feynman-technique.md) |
| I want to take stock of my life and choose what to work on | [Wheel of Life](../methods/reflection-and-learning/wheel-of-life.md) |
| I want to get better at judging important decisions | [Decision Journal](../methods/reflection-and-learning/decision-journal.md) |
