# Systems Thinking: cheat sheet

> See a problem as a connected whole with feedback loops.

Full guide: [Systems Thinking](../methods/mental-models/systems-thinking.md)

## Use it when

- A problem keeps returning in a different form
- A fix produced side effects
- Different people each see one part of the cause

## Steps

1. Describe the problem as a pattern over time
2. Set the boundary of the system
3. List the key variables (things that go up or down)
4. Draw arrows between them and mark + or -
5. Find loops: reinforcing (R) or balancing (B)
6. Mark delays
7. Tell the story of each loop aloud
8. Pick a leverage point and test a small change

## Key questions

- What pattern keeps repeating?
- What reinforces it, and what limits it?
- Where are the delays?
- Where would a small change have a large effect?

## Watch out for

- Drawing everything
- Arrows with no signs
- Ignoring delays
- Treating the diagram as fact
