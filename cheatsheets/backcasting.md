# Backcasting: cheat sheet

> Define the future you want, then work backwards to today.

Full guide: [Backcasting](../methods/planning/backcasting.md)

## Use it when

- A large goal is far away and the path is unclear
- Small improvements will not be enough
- You need milestones in the right order

## Steps

1. Describe the future state concretely, with a date
2. Describe the present honestly
3. Ask what must be true just before the goal; repeat back to today
4. Check order and dependencies
5. Find the gaps and the riskiest milestone
6. List actions, starting with the nearest milestone
7. Test feasibility and adjust date, scope or route
8. Set the first step and a review date

## Key questions

- What must be true just before this?
- What is the biggest obstacle between here and there?
- What do we need that we do not yet have?
- What can we start this week?

## Watch out for

- A vague destination
- Ignoring constraints
- No first step
