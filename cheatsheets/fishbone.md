# Fishbone Diagram: cheat sheet

> Map every possible cause on a fish skeleton before choosing where to dig.

Full guide: [Fishbone Diagram](../methods/root-cause/fishbone.md)

## Use it when

- The problem has many possible causes
- A group needs a shared picture
- A single 'why' chain keeps branching

## Steps

1. State the problem specifically and put it at the head
2. Draw the spine and choose category bones (for example People, Process, Tools, Materials, Environment, Management)
3. Brainstorm causes under each category
4. Ask 'why does this happen?' to add sub-causes
5. Mark likely causes using evidence
6. Verify the top candidates before acting

## Key questions

- What could cause this under each category?
- Which causes appear in more than one place?
- What evidence supports this cause?

## Watch out for

- Treating all causes as equal
- A vague problem statement
- Drawing it and never testing the candidates
