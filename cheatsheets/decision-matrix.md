# Decision Matrix: cheat sheet

> Compare options against weighted criteria so the choice rests on stated reasons.

Full guide: [Decision Matrix](../methods/decision-making/decision-matrix.md)

## Use it when

- Three or more options with several criteria
- A group must agree and explain the choice
- Gut feeling and analysis disagree

## Steps

1. State the decision and goal
2. List options and apply must-have filters
3. Choose 4-8 distinct criteria
4. Agree on weights before scoring
5. Score each option on a defined scale
6. Multiply by weight and add up
7. Test sensitivity by changing weights slightly
8. Decide and record the reasons

## Key questions

- Which criteria really matter, and how much?
- Does the top result feel right? If not, why?
- Does the winner change if a weight changes?

## Watch out for

- Too many or overlapping criteria
- False precision (61 vs 58 is a tie)
- Tuning weights until the favourite wins
