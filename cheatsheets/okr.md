# OKR: cheat sheet

> One inspiring objective, a few measurable key results, reviewed every week.

Full guide: [OKR](../methods/planning/okr.md)

## Use it when

- A team needs to focus on a few outcomes
- Several groups must pull in the same direction
- A new quarter or year is starting

## Steps

1. Start from strategy: what matters most this period?
2. Write 1-3 inspiring objectives
3. Write 2-5 key results per objective, each from a start value to a target
4. Check they measure outcomes, not activities
5. Mark committed vs aspirational
6. Align with other teams
7. Plan initiatives
8. Check in weekly; score 0-1 at the end and reflect

## Key questions

- What outcome would show we reached the objective?
- Is this key result an outcome or an activity?
- Where are we now, and what is the target?
- How confident are we this week?

## Watch out for

- Too many objectives
- Activities as key results
- Sandbagging or tying OKRs to pay
- Set and forget
