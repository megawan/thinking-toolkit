# Morphological Analysis: cheat sheet

> Break a problem into parameters, list options for each, and combine them.

Full guide: [Morphological Analysis](../methods/ideation/morphological-analysis.md)

## Use it when

- The problem has several separate design choices
- You want to explore the whole space of options
- Designing a product, service or event from scratch

## Steps

1. State the problem
2. Identify 4-7 independent parameters
3. List 3-5 options for each, including unusual ones
4. Draw the box: one row per parameter
5. Trace combinations, including odd ones
6. Remove impossible pairs
7. Shortlist and evaluate against criteria
8. Develop and test the best

## Key questions

- What independent choices define a solution?
- What other options exist for this parameter?
- What would an odd combination look like?

## Watch out for

- Too many or overlapping parameters
- Only two options per row
- Not evaluating the shortlist
