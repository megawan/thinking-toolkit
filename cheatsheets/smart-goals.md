# SMART Goals: cheat sheet

> Specific, Measurable, Achievable, Relevant, Time-bound.

Full guide: [SMART Goals](../methods/planning/smart-goals.md)

## Use it when

- You have a wish and need to make it actionable
- A team must agree what 'done' means
- You are reviewing whether a goal is clear

## Steps

1. Write a first draft
2. Make it specific: what, who, why
3. Add a measure: a number or clear condition
4. Check it is achievable with your time and resources
5. Check it is relevant to a bigger aim
6. Set a deadline and milestones
7. Write the final sentence
8. Plan the first action and a review date

## Key questions

- What exactly will be done?
- How will we know it is achieved?
- Is it possible with what we have?
- Why does it matter?
- By when?

## Watch out for

- A metric that does not reflect the aim
- Output without outcome
- Too rigid to adapt
- No review
