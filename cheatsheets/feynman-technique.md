# Feynman Technique: cheat sheet

> Explain it simply as if to a beginner, and let the gaps show.

Full guide: [Feynman Technique](../methods/reflection-and-learning/feynman-technique.md)

## Use it when

- Learning a new subject deeply
- Preparing to teach, present or take an exam
- Checking that you really understand something

## Steps

1. Choose one small concept
2. Study it briefly, then close the sources
3. Write or say an explanation in plain language, with examples
4. Mark every gap, hesitation and unexplained term
5. Go back to the source to fill the gaps
6. Rewrite it shorter and simpler
7. Test it on a real person
8. Review again after a few days

## Key questions

- Can I explain this without jargon?
- Why is it true? What is an example?
- Where did I hesitate or hand-wave?
- Can a beginner repeat it back?

## Watch out for

- Reading the source while explaining
- Using jargon as a shortcut
- Mistaking fluency for understanding
