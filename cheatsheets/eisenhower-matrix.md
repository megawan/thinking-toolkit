# Eisenhower Matrix: cheat sheet

> Sort tasks by urgency and importance.

Full guide: [Eisenhower Matrix](../methods/prioritisation/eisenhower-matrix.md)

## Use it when

- The to-do list is long and everything feels pressing
- You mostly react and rarely plan
- A team needs to agree on priorities

## Steps

1. Brain-dump all tasks
2. Define what 'important' means (your goals)
3. Rate urgency and importance for each task
4. Place tasks in a quadrant
5. Do now / schedule / delegate / eliminate
6. Put quadrant 2 tasks in the calendar
7. Review weekly

## Key questions

- Does this serve a goal I would name?
- Is there a real consequence if it waits?
- Could someone else do it as well?
- What happens if it is never done?

## Watch out for

- Everything marked important
- Living in quadrant 1
- Never scheduling quadrant 2
