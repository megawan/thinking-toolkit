# Expected Value and Opportunity Cost: cheat sheet

> Weigh outcomes by their chance, and count what the next-best option would have given.

Full guide: [Expected Value and Opportunity Cost](../methods/decision-making/expected-value-and-opportunity-cost.md)

## Use it when

- Outcomes are uncertain and can be estimated
- Time or money has competing uses
- Comparing a risky option with a safe one

## Steps

1. Define options, including the next-best alternative
2. List possible outcomes, including bad ones
3. Estimate probabilities that sum to 100 percent per option
4. Estimate values in one unit
5. EV = sum of probability x value
6. Opportunity cost = value of the best alternative forgone
7. Compare net gain; check the worst case and the spread
8. Test sensitivity of key probabilities

## Key questions

- What are all the outcomes, and how likely is each?
- What is the best alternative use of this time or money?
- Can I survive the worst case?
- What if my probability is wrong by 10 points?

## Watch out for

- Treating estimates as facts
- Ignoring a ruinous outcome because EV is positive
- Comparing only with doing nothing
