# Occam's and Hanlon's Razor: cheat sheet

> Prefer the simpler explanation, and do not assume malice where error will do.

Full guide: [Occam's and Hanlon's Razor](../methods/mental-models/occams-and-hanlons-razor.md)

## Use it when

- Several explanations fit the same evidence
- A system fails and you need a place to start
- Someone's behaviour seems hostile and you are about to react

## Steps

1. List the explanations that fit the evidence
2. List the assumptions each needs
3. Test the one with the fewest, cheapest to check first
4. For behaviour: list the innocent explanations
5. Rank by how common they are in this setting
6. Ask a question instead of making an accusation
7. Treat repeated patterns with a direct conversation

## Key questions

- What is the simplest explanation that fits all the facts?
- How many things must be true for this one to hold?
- What innocent explanations are there?

## Watch out for

- Treating the razor as proof
- Using Hanlon's razor to excuse repeated harm
- Stopping the search too early
