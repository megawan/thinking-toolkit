# Bayesian Thinking: cheat sheet

> Start from the base rate, then update in proportion to how strong the evidence is.

Full guide: [Bayesian Thinking](../methods/mental-models/bayesian-thinking.md)

## Use it when

- Interpreting a test or signal where false alarms are possible
- Forecasting as news arrives
- Judging a surprising claim

## Steps

1. State the hypothesis clearly
2. Find the base rate (prior)
3. Ask how likely the evidence is if the hypothesis is true, and if it is false
4. Compare the two: the bigger the ratio, the stronger the evidence
5. Update your belief by that amount
6. Use natural frequencies (think of 1,000 cases)
7. Repeat with each new piece of evidence

## Key questions

- How common is this to begin with?
- How likely would I see this evidence if I were wrong?
- How much should this move my belief?

## Watch out for

- Ignoring the base rate
- Treating weak evidence as strong
- Confusing P(E given H) with P(H given E)
