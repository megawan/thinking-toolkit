# First Principles: cheat sheet

> Break a problem to what is certainly true, then build up from there.

Full guide: [First Principles](../methods/mental-models/first-principles.md)

## Use it when

- The standard solution is too costly or slow
- You hear 'that is just how it works'
- There is no good precedent

## Steps

1. Define the problem or goal
2. List current assumptions
3. Challenge each: how do I know this is true?
4. Separate hard facts from conventions
5. Reduce to fundamentals
6. Rebuild a solution from the facts only
7. Compare with the existing one and test the riskiest part

## Key questions

- What do we know for certain, and how?
- What is this made of at the most basic level?
- If we started from scratch today, what would we do?
- Which constraint is real and which is inherited?

## Watch out for

- Stopping while an 'assumption' is still a belief
- Treating every convention as wrong
- Ignoring practical limits
